# Kaipai Web Precise Edit

用于通过开拍 Web 编辑器制作中文单人口播“网感精剪”的 Codex Skill。

它会引导智能剪辑流程：上传视频、等待语音分析、在文字快剪中处理无声与明确的口误片段、规范字幕中的 `GPT` 写法，并使用选定模板、音乐和音效完成处理与导出。

## 适用场景

- 中文单人口播、教程、观点表达类视频
- 希望基于逐字稿删除静音、犹豫或指定重录片段
- 希望在开拍 Web 中应用字幕模板并导出 1080P MP4

不适用于多人对话、非中文口播或以素材混剪为主的视频；这些内容应先选择更合适的剪辑工作流。

## 安装

将仓库克隆到 Codex Skills 目录：

```bash
git clone https://github.com/tianqiyun3090-bot/kaipai-web-precise-edit.git \
  ~/.codex/skills/kaipai-web-precise-edit
```

之后在 Codex 中直接提及 `kaipai-web-precise-edit`，或请求使用开拍网页对口播视频进行网感精剪。

## 默认行为

- 仅在用户明确授权后上传指定本地视频。
- 使用开拍 Web 完成全部上传、编辑、处理和下载操作。
- 删除全部识别出的“无声片段”；保留完整、可理解的短句。
- 统一将独立的 `gpt`、`Gpt` 等写为 `GPT`。
- 默认采用“基础白金”模板，并启用音乐与音效。
- 默认导出 1080P MP4，并将下载文件保存为 `原文件名-网感精剪-YYYYMMDD-HHMM.mp4`。

## 注意事项

处理与导出可能消耗开拍权益。对于单条视频，在用户已明确要求生成时才会开始处理；批量视频则应在首次提交前取得用户确认。
